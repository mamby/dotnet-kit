# Mamby.Maui

Opinionated .NET MAUI utilities for modern cross-platform applications.

## Bottom Sheet

`Mamby.Maui.Controls.Sheets.BottomSheetView` provides a reusable bottom sheet control built on first-party .NET MAUI primitives.

Features:

- Modal scrim with tap-to-dismiss.
- Animated show and hide transitions.
- Configurable maximum height ratio.
- Scrollable sheet content.
- Pull-to-dismiss from the sheet chrome and top of scroll content.
- Android, iOS, Mac Catalyst, and Windows content drag support.
